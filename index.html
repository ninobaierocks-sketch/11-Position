How Drop Down Menus Work

The parent list item needs position: relative so the dropdown menu can be positioned with position: absolute.

The submenu is hidden by default using display: none. When the user hovers over Products, the submenu appears using display: block.

This allows the dropdown menu to appear directly underneath the Products tab without moving the other content.
